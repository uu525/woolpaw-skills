# WoolPaw 使用方法

**WoolPaw 已上线即梦技能，在即梦技能中搜索 `WoolPaw` 即可找到。**

作者：闪亮的uu · [项目首页](https://github.com/uu525/woolpaw-skills) · [联系作者](https://github.com/uu525)

## 先准备什么

1. 能使用相应技能功能的即梦或豆包账号，以及图片／视频生成所需的权限和额度。
2. 一张你有权使用、角色主体清楚的毛绒小动物参考图。进阶版如需参考特定字体或透视，请另外准备有权使用的参考素材。
3. 明确动物、配色、穿搭，或要加入的准确文字。视频版准备最终想呈现的完整角色画面。

仓库提供 Skill 指令文件，不包含生成模型、API 密钥、平台会员或生成额度；无需为了下载文件准备 GitHub 账号或编程环境。

## 路径一：直接在即梦中找到技能

1. 在 PC 端打开即梦并登录。
2. 进入技能页，搜索 **WoolPaw**。
3. 找到作者发布的 WoolPaw 技能，根据需求选择并使用。
4. 上传自己的参考图，发送下方对应示例指令，并根据实际返回结果调整。

上线情况及上述入口由作者确认。搜索结果、展示名称及可见功能以你的账号当前页面为准；这里不声称已重新实测所有账号或版本。

## 路径二：下载文件后导入

1. 下载 [三个 Skill 轻量包](https://raw.githubusercontent.com/uu525/woolpaw-skills/main/downloads/woolpaw-skills-v1.0.0.zip)，或在 [skills 目录](https://github.com/uu525/woolpaw-skills/tree/main/skills) 下载所需的单个 `.md` 文件。
2. ZIP 请先解压。用于导入的是三个子目录里的 **`.md` 文件**，不是整个 ZIP，也不是教程文件。
3. **即梦：**在 PC 端进入技能页，通过页面提供的导入入口选择对应 `.md` 文件。
4. **豆包：**进入技能窗口，通过该窗口提供的导入入口选择对应 `.md` 文件。
5. 按平台当前界面完成导入，然后使用该技能，上传自己的参考图并填写需求。

导入入口来自作者说明。本次仓库发布未重新实测平台内导入或生成，不编造额外按钮名称。如果没有看到相应入口，请先核对所在端、账号功能及平台当前界面。

## 01 基础版：统一风格毛绒角色

文件：`skills/basic/WoolPaw-毛绒-简单版.md`

**输入：**一张毛绒角色风格参考图＋动物、颜色、穿搭需求。

```text
请参考我上传的图片，生成同一系列的三只毛绒小动物：
1. 浅蓝色小鸟，蓝色棒球帽，奶白连帽衫，浅蓝背景；
2. 淡紫色小熊，反戴棒球帽，格子衬衫，薄荷绿背景；
3. 奶黄色垂耳兔，针织贝雷帽，碎花裙，柔和绿色背景。
保持长条形态、清晰植绒纹理和低饱和马卡龙配色，竖版 9:16。
```

**预期：**不同角色保留统一的植绒质感与色彩调性。以上是可复用的演示输入，不是示例成品的完整原始生成记录。

局部修改示例：`只把小鸟的帽子改成奶白色，其他造型、衣服、背景和植绒质感保持不变。`

## 02 进阶版：透视动作＋定制植绒文字

文件：`skills/perspective/WoolPaw-毛绒-加透视动作加定制植绒字装饰.md`

**输入：**已有毛绒角色画面＋准确的文字内容；需要特定字形或视角时，附有权使用的字体／透视参考图。

```text
请基于我上传的毛绒小老虎图片，保留角色的核心特征、穿搭和植绒质感。
让小老虎朝镜头伸出前爪，使用夸张广角俯拍与近大远小的透视。
在背景加入奶白色立体植绒文字“WoolPaw”，搭配低饱和暖橙渐变和柔和圆形光斑。
文字自然融入空间，不遮住脸，竖版 9:16。
```

**预期：**带明显透视动作、渐变光影及毛绒文字的角色图。请核对文字拼写、肢体与角色一致性。

默认会启用夸张透视；不需要时明确说：`关闭鱼眼与夸张透视，使用普通居中构图，只添加文字。`

## 03 视频版：5 秒动感开场

文件：`skills/video/WoolPaw-毛绒-动感视频-炫技动作版.md`

**输入：**一张完整、清晰的毛绒角色图片，可包含已经排好的装饰文字。

```text
请把我上传的毛绒角色图制作成 5 秒动感开场。
根据角色性格设计一次明显的转身、弹跳或探身挥手动作，带卡通弹性。
保持原有角色、植绒质感、配色和文字内容；文字存在时加入逐显动效。
最后收稳，尽量回到参考图的完整构图。比例与原图一致。
```

**预期：**单段 5 秒角色开场视频；不是长剧情或多段自动剪辑工具。原文件设定为提交任务后不主动轮询；需要查进度时可追问 `刚才的视频生成好了吗？`，实际查询能力以平台为准。

## 常见问题

**下载后变成网页或 `.txt`？** 单文件请使用 GitHub 文件页的原始文件下载功能；也可直接下载 ZIP。确认扩展名保持 `.md`，不要把 HTML 网页当技能文件导入。

**为什么没有原始参考图？** 创作时部分参考素材来自第三方，未随仓库公开。请用你自己有权使用的图片。作品展示素材的许可与 Skill 文本不同。

**可以在 Codex 或其他平台直接安装吗？** 本版按作者的即梦／豆包导入流程发布，没有做其他平台的安装适配或兼容性验证。

**可以商用 Skill 文本吗？** 文本按 MIT 许可提供；仓库中的图片和视频仅供展示学习，其他用途请联系作者。见 [文本许可](https://github.com/uu525/woolpaw-skills/blob/main/LICENSE) 和 [视觉素材说明](https://github.com/uu525/woolpaw-skills/blob/main/ASSETS-LICENSE.md)。
