# WoolPaw 使用方法

**WoolPaw 已上线即梦技能，在即梦技能中搜索 `WoolPaw` 即可找到。**

作者：闪亮的uu · [项目首页](https://github.com/uu525/woolpaw-skills) · [联系作者](https://github.com/uu525)

**两个生图 Skill 直接输入文字描述，无需上传参考图；只有视频 Skill 需要上传已经生成好的首帧图。**

以下使用建议根据作者《WoolPaw Skill 使用说明》整理，并结合作者最新说明更新了输入要求。

## 先准备什么

| 使用哪个 Skill | 需要准备什么 | 是否需要上传图片 |
| --- | --- | --- |
| 简单动作／基础版 | 想要的动物、颜色、服装、配饰和动作；不确定的细节可以让 AI 自由发挥 | 不需要 |
| 加透视加字体／进阶版 | 角色描述、镜头角度、动作，以及准确的植绒文字内容 | 不需要 |
| 登场视频／视频版 | 已经生成好的清晰完整首帧图，以及时长、动作和结束方式 | 需要上传首帧图 |

你还需要能使用相应功能的即梦或豆包账号，以及图片／视频生成所需的权限和额度。仓库提供 Skill 指令文件，不包含生成模型、API 密钥、平台会员或生成额度；下载不需要 GitHub 账号或编程环境。

## 路径一：直接在即梦中找到技能

1. 在 PC 端打开即梦并登录。
2. 进入技能页，搜索 **WoolPaw**。
3. 找到作者发布的技能，根据需求选择简单动作、加透视加字体或登场视频。
4. **生图：**直接输入下方的文字描述，不需要上传参考图。
5. **视频：**先上传已经生成好的首帧图，再说明动画需求。

上线情况及入口由作者确认。搜索结果、展示名称及可见功能以你的账号当前页面为准，本次文档更新没有重新实测平台内生成。

## 路径二：下载文件后导入

1. 下载 [三个 Skill 轻量包](https://github.com/uu525/woolpaw-skills/releases/download/v1.0.1/woolpaw-skills-v1.0.1.zip)，或在 [skills 目录](https://github.com/uu525/woolpaw-skills/tree/main/skills) 下载所需的单个 `.md` 文件。
2. ZIP 请先解压。用于导入的是三个子目录里的 **`.md` 文件**，不是整个 ZIP，也不是教程文件。
3. **即梦：**在 PC 端进入技能页，通过页面提供的导入入口选择对应 `.md` 文件。
4. **豆包：**进入技能窗口，通过该窗口提供的导入入口选择对应 `.md` 文件。
5. 按平台当前界面完成导入，使用对应技能：两个生图 Skill 直接填写文字需求；视频 Skill 上传生成好的首帧图后填写动画需求。

Skill 主要帮助你复用创作规则、整理提示词。获得提示词后，在当前平台支持的生图工具中使用文字生成图片；生成视频时，将提示词与生成好的首帧图用于支持相应功能的视频工具。如果宿主平台可直接生成，也可沿其生成流程继续。具体能力以所用平台为准。

## 01 简单动作／基础版：先确定角色形象

文件：`skills/basic/WoolPaw-毛绒-简单版.md`

适合测试毛绒质感、配色、穿搭和基础动作。**不用上传参考图，直接描述你想要的角色。**

**提示词填写建议：动物＋颜色＋服装／配饰＋动作。** 还可以补充表情、背景和画面比例。

```text
使用「简单动作」Skill，帮我设计一只奶黄色毛绒垂耳兔，
戴针织贝雷帽、穿碎花裙，向镜头挥手。
保持清晰植绒质感和低饱和配色，背景与其他细节请自由发挥。
```

也可以少写一点，让 AI 自己想象：

```text
使用「简单动作」Skill，帮我设计一只软萌的毛绒小动物。
动物种类、配色、穿搭和基础动作请自由发挥，保持统一的植绒质感。
```

需要做系列角色时，可以这样写：

```text
使用「简单动作」Skill，生成同一系列的浅蓝小鸟、淡紫小熊和奶黄垂耳兔。
分别搭配连帽衫、格子衬衫和碎花裙，设计各自的挥手或探身动作，
保持统一植绒质感与低饱和配色，竖版 9:16。
```

如果你有喜欢的参考图，也可以自愿提供，帮助指定风格或修改已有形象；这不是生图的前置条件。

## 02 加透视加字体／进阶版：加入镜头表现力

文件：`skills/perspective/WoolPaw-毛绒-加透视动作加定制植绒字装饰.md`

适合加入鱼眼透视、俯拍、仰拍，以及与画面风格一致的植绒艺术字。**同样可以只输入文字，不需要上传角色图。**

**提示词填写建议：角色形象＋镜头角度＋动作＋植绒文字＋背景氛围。** 文字请写清准确内容，例如 `Rabbit`、`WoolPaw` 或自己的名称。

```text
使用「加透视加字体」Skill，设计一只奶黄色毛绒垂耳兔，
戴针织贝雷帽、穿碎花裙，以高角度鱼眼俯拍，让它向镜头递出小花。
背景加入奶白色植绒艺术字“Rabbit”，搭配柔和渐变与圆形光斑。
文字不要遮住脸，竖版 9:16。
```

如果想延续一张已经满意的角色图，可以选择上传它，并说明要保留的细节：

```text
使用「加透视加字体」Skill，保留这只小兔子的造型和穿搭，
改成高角度鱼眼俯拍，让它向镜头递出小花，背景加入植绒艺术字“Rabbit”。
```

上面的续图方式是可选用法；没有图片时，直接使用前面的完整文字描述即可。默认会启用夸张透视，不需要时明确说：`关闭鱼眼与夸张透视，使用普通居中构图。`

## 03 登场视频／视频版：让定稿角色动起来

文件：`skills/video/WoolPaw-毛绒-动感视频-炫技动作版.md`

**先上传已经生成好的首帧图。** 可以使用前两个生图 Skill 生成并选定的成品图，确保角色与构图清晰、完整；如有装饰文字，先确认拼写与排版。

**提示词填写建议：时长＋角色动作＋镜头运动＋结束方式。**

```text
我已上传生成好的首帧图。使用「登场视频」Skill，为这只小兔子设计一段 5 秒登场动画。
转身、挥手，耳朵跟着轻轻摆动，镜头轻轻推近，
保持角色、穿搭、植绒质感和原有文字，最后尽量回到首帧图的姿势与构图并定格。
```

预期为单段 5 秒角色开场视频。原文件设定为提交任务后不主动轮询；需要查进度时可追问 `刚才的视频生成好了吗？`，实际查询能力以平台为准。

## 推荐创作顺序

**简单动作 → 加透视加字体 → 登场视频**

先用文字确定角色，再用文字描述所需透视与植绒字；需要延续同一形象时可选用已有成品图。选定满意的成品后，将它上传为视频首帧图。三个 Skill 也可以根据需求单独调用。

## 常见问题

**两个生图 Skill 必须传图吗？** 不需要。直接描述动物、颜色、穿搭、动作；进阶版再加镜头角度和文字即可。参考图仅在你希望指定风格或延续已有形象时自愿提供。

**视频需要传什么？** 上传已经生成好的首帧图，然后描述时长、动作和结束方式。

**下载后变成网页或 `.txt`？** 单文件请使用 GitHub 文件页的原始文件下载功能；也可直接下载 ZIP。确认扩展名保持 `.md`，不要把 HTML 网页当技能文件导入。

**为什么没有第三方参考图？** 部分历史创作参考素材来自第三方，未随仓库公开；这不影响两个生图 Skill 通过文字使用。自行选择附图时，请使用有权使用的图片。

**可以在 Codex 或其他平台直接安装吗？** 本版按作者的即梦／豆包导入流程发布，没有做其他平台的安装适配或兼容性验证。

**可以商用 Skill 文本吗？** 文本按 MIT 许可提供；仓库图片与视频仅供展示学习，其他用途请联系作者。见 [文本许可](https://github.com/uu525/woolpaw-skills/blob/main/LICENSE) 和 [视觉素材说明](https://github.com/uu525/woolpaw-skills/blob/main/ASSETS-LICENSE.md)。
